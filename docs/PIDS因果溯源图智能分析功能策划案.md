# PIDS 因果溯源图智能分析功能策划案

> **项目名称**: 智联天鉴 - PIDS因果溯源图智能分析模块  
> **版本**: v1.0  
> **日期**: 2026-01-28

---

## 一、功能概述

基于现有PIDS因果溯源图系统，扩展三大智能分析功能：

| 功能模块 | 核心能力 | 价值体现 |
|----------|----------|----------|
| **特征提取引擎** | 从因果溯源图中提取结构化特征向量 | 将图谱转化为可量化的数学表示 |
| **行为建模系统** | 基于正常行为特征训练异常检测模型 | 建立系统行为基线，识别偏离模式 |
| **检测性能评估** | 多维度评估检测准确性和效率 | 量化验证模型有效性 |

#### 2.1.2 特征提取算法

| 特征类别 | 提取方法 | 输出维度 |
|----------|----------|----------|
| 图结构特征 | NetworkX图分析 | 10维 |
| 节点特征 | One-Hot + Word2Vec | 64维 |
| 边特征 | 统计聚合 | 8维 |
| 序列特征 | LSTM编码 | 32维 |
| 语义特征 | 预训练嵌入 | 16维 |
| **总计** | 特征拼接 | **130维** |

### 3.2 数据库表设计

```sql
-- 特征数据表
CREATE TABLE feature_vectors (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    attack_id VARCHAR(64) NOT NULL,
    feature_json TEXT NOT NULL,
    feature_version VARCHAR(20),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_attack_id (attack_id)
);

-- 训练模型表
CREATE TABLE trained_models (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    model_name VARCHAR(100) NOT NULL,
    model_type VARCHAR(50) NOT NULL,
    model_path VARCHAR(255),
    params_json TEXT,
    accuracy DECIMAL(5,4),
    precision_score DECIMAL(5,4),
    recall_score DECIMAL(5,4),
    f1_score DECIMAL(5,4),
    auc_roc DECIMAL(5,4),
    status ENUM('training', 'completed', 'deployed', 'archived'),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    trained_at DATETIME
);

-- 评估记录表
CREATE TABLE evaluation_records (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    model_id BIGINT,
    test_set_size INT,
    accuracy DECIMAL(5,4),
    precision_score DECIMAL(5,4),
    recall_score DECIMAL(5,4),
    f1_score DECIMAL(5,4),
    auc_roc DECIMAL(5,4),
    confusion_matrix JSON,
    per_class_metrics JSON,
    avg_latency_ms INT,
    p95_latency_ms INT,
    evaluated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (model_id) REFERENCES trained_models(id)
);
```
