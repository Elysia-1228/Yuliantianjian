## 1. 项目概述

**御链天鉴**是一套面向企业/园区网络的智能 IDS（入侵检测系统）全栈平台，核心创新点：

| 特性 | 说明 |
|------|------|
| **双引擎检测** | NIDS（网络层） + PIDS（主机层）协同，覆盖外部入侵与内部异常 |
| **AI + 规则双重** | TransEC-GAN（深度学习）+ Snort风格规则引擎并行检测，互为补充 |
| **因果溯源图** | 基于 KAIROS 论文方法，构建进程→文件→网络的有向因果图 |
| **区块链存证** | 告警事件经 Hyperledger Fabric 上链，防篡改审计 |
| **实时推送** | WebSocket 连接将检测告警毫秒级推送到前端仪表盘 |
| **35+ 攻击类型** | 覆盖 DoS/DDoS/PortScan/BruteForce/WebAttack/Infiltration/Bot 七大类 |

### 核心数据流路径

**NIDS 告警流**
```
Scapy 网卡抓包
  → FlowStats 78维特征提取
  → 规则引擎（滑动窗口计数）OR TransEC-GAN模型推断
  → 命中阈值 → 计算威胁等级(1~5) + 获取攻击上下文(进程/文件)
  → POST http://localhost:8985/api/analysis/alert
  → BackCode 保存 MySQL + 推送 WebSocket
  → 前端实时展示告警卡片
```

**PIDS 溯源图流**
```
前端点击溯源节点
  → GET /api/tracing/result (溯源列表)
  → 用户触发生成图谱
  → POST /api/tracing/result/generate-graph
  → TracingServiceImpl.generateTraceGraph()
  → 查询 MySQL potential_threat_alert（含affectedProcess/affectedFile）
  → buildUnifiedGraph() 或 buildSimpleGraph()
  → 返回 nodes+edges JSON
  → 前端 PIDSGraph (AntV G6) 渲染
  → pidsAdapter.ts 将后端图谱 → KAIROS 格式图谱增强
  → 右侧面板调用 PIDS FastAPI :7890 提取130维特征
```

## 4. NIDS 网络入侵检测系统详解

### 4.1 架构设计

```
网卡流量
  │  Scapy sniff() 抓包（仅监听WLAN/以太网，排除Loopback）
  ▼
packet_callback()
  ├── extract_features()  ──→  FlowStats 78维特征更新（CICIDS2017对齐）
  │
  ├── rule_engine_check() ──→  6个规则检测器（滑动窗口）
  │   ├── rule_check_portscan()     40端口/30s → PortScan
  │   ├── rule_check_synflood()    300 SYN/10s → DoS/SYN Flood
  │   ├── rule_check_bruteforce()   20次/30s  → BruteForce
  │   ├── rule_check_udpflood()   1000 UDP/10s→ DDoS/UDP Flood
  │   ├── rule_check_icmpflood()   100 ICMP/10s→ DoS/ICMP Flood
  │   └── rule_check_suspicious()   15次/30s  → WebAttack/Infiltration/Bot
  │
  └── model_classify()    ──→  TransEC-GAN Discriminator
      │  (仅当规则引擎未命中且包数>=8时执行)
      ├── StandardScaler(78维→归一化)
      ├── PCA(25维，95.6%方差)
      ├── TransformerEncoder + Discriminator
      │   → real_score（OOD真实性分数）
      │   → class_logits → softmax → 8类概率
      │   → attack_prob = 1 - P(Benign)
      └── 命中条件: attack_prob>0.92 & real_score>0.65 & confidence>0.80
```

### 4.2 TransEC-GAN 模型架构

| 组件 | 说明 |
|------|------|

### 4.5 威胁等级算法

**规则引擎威胁等级**
```python
def calculate_rule_threat_level(attack_class, detail_str):
    base = ATTACK_BASE_SEVERITY[attack_class]  # 1~5
    count = 从detail_str提取检测数量
    ratio = count / 攻击类型对应阈值
    intensity_bonus = 2 if ratio>=10 else (1 if ratio>=5 else 0)
    return clamp(base + intensity_bonus, 1, 5)
```

**AI模型威胁等级**
```python
def calculate_model_threat_level(attack_prob, confidence, real_score, attack_class):
    base = ATTACK_BASE_SEVERITY[attack_class]
    if attack_prob > 0.95 and confidence > 0.85:  # 严重
        level = base + 1
    elif attack_prob > 0.90 and confidence > 0.75:  # 高风险
        level = base
    elif attack_prob > 0.85:                         # 中风险
        level = max(base - 1, 2)
    else:                                            # 低风险
        level = 2
    return clamp(level, 1, 5)
```

## 5. PIDS 主机入侵检测系统详解

### 5.1 架构设计

```
溯源图数据（JSON格式：nodes + edges）
  │  来源：Java后端从告警记录组装 或 CDM适配器转换
  ▼
FeatureExtractor.extract()       ──→  130维特征向量
  │
  ├── 图结构特征 (dim 0~14, 15维)
  │   node_count / edge_count / graph_density / avg_degree
  │   max_path_length / clustering_coefficient / ...
  │
  ├── 节点特征 (dim 15~54, 40维)
  │   process_node_count / file_node_count / socket_node_count
  │   attacker_node_count / 各类节点中心性统计 / ...
  │
  ├── 边特征 (dim 55~79, 25维)
  │   exec_edge_count / read_edge_count / write_edge_count
  │   connect_edge_count / fork_edge_count / cross_type_ratio / ...
  │
  ├── 序列特征 (dim 80~109, 30维)
  │   time_span / interval_mean / interval_std
  │   burst_count / operation_entropy / periodic_pattern_score / ...
  │
  └── 语义特征 (dim 110~129, 20维)
      sql_injection_score / xss_score / webshell_score
      rce_score / privilege_escalation_score
      overall_threat_score / anomaly_score / ...
  │
  ▼
L1 EnsembleDetector（快速筛选）
  ├── IsolationForest
  ├── LOF (Local Outlier Factor)
  ├── OCSVM (One-Class SVM)
  └── XGBoost
  输出: l1_score（异常分数 0~1）
  │
  ▼
L2 VAEClassifier（深度确认）
  ├── VAE Encoder（变分自编码器）
  └── MLP Classifier
  输出: l2_score（异常分数 0~1）
  │
  ▼
融合分数: final_score = 0.3 * l1_score + 0.7 * l2_score
  │
  ▼
prediction: "anomaly" / "normal"
```

**连接**：
```
ws://localhost:8985/ids/stream
（生产环境由 VITE_IDS_WS_URL 环境变量覆盖）
```

**认证**（连接建立后发送）：
```json
{"type": "AUTH", "token": "eyJ...JWT..."}
```

**接收格式**（服务端推送的 `potentialThreatAlert` JSON）：
```json
{
  "threatId": "NIDS-1710000000000",
  "threatLevel": 4,
  "impactScope": "192.168.1.88:40000 -> 192.168.0.106:22 | BruteForce/SSH",
  "occurTime": "2026-03-17 20:00:00",
  "sourceIp": "192.168.1.88",
  "targetIp": "192.168.0.106",
  "attackType": "BruteForce/SSH",
  "affectedProcess": "[\"sshd\", \"pam_unix\"]",
  "affectedFile": "/var/log/auth.log",
  "message": "[TCP] ...",
  "status": "未处理"
}
```

**前端解析（`IDSSocket.onmessage`）**：
- 解析 `impactScope` → `sourceIp`/`targetIp`/`type`
- 映射 `threatLevel` → `riskLevel`（4-5→High, 3→Medium, 1-2→Low）
- 封装为 `ThreatEvent` 对象，调用 `onMessage` 回调更新页面

**断线重连**：3秒自动重连，组件卸载时调用 `disconnect()`

## 9. 数据库结构详解

**数据库名**：`net_safe`（MySQL 8.0，端口3306）

### 核心表

#### `potential_threat_alert`（NIDS告警主表）
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INT PK | 自增主键 |
| `threat_id` | VARCHAR | NIDS-{时间戳} |
| `threat_level` | INT | 威胁等级 1~5 |
| `impact_scope` | VARCHAR | 攻击四元组字符串 |
| `occur_time` | DATETIME | 发生时间 |
| `source_ip` | VARCHAR | 攻击源IP |
| `target_ip` | VARCHAR | 目标IP |
| `attack_type` | VARCHAR | ★ 新增字段（自动迁移） |
| `affected_process` | TEXT | ★ 新增字段（JSON数组字符串） |
| `affected_file` | VARCHAR | ★ 新增字段（文件路径） |
| `message` | TEXT | ★ 新增字段（详细描述） |
| `status` | VARCHAR | 处理状态 |
| `create_time` | DATETIME | 入库时间 |

> **注意**：`attack_type`/`affected_process`/`affected_file`/`message` 4个字段通过 `DatabaseAutoUpdater` 在运行时自动 ALTER TABLE 添加，`schema.sql` 中没有这些字段定义。

#### `threat_source_tracing`（溯源结果表）
存储由 `TracingController.generateGraph()` 生成的图谱结果（含历史溯源记录）。

#### `host_status_monitor` / `process_monitor`
由 `scripts/host_monitor_agent.py` 周期性采集 psutil 数据写入。

### 10.3 数据聚合层（alertAggregator.ts）

```typescript
interface AggregatedAlert {
  sourceIp: string;          // 攻击源IP
  count: number;             // 攻击次数
  severity: string;          // 最高威胁等级
  primaryThreatType: string; // 主要攻击类型
  threatTypes: string[];     // 所有攻击类型列表
  lastSeen: string;          // 最近一次时间
  targetIps: string[];       // 目标IP列表
}
```

`aggregateAlertsByIP()` 将告警历史按 `sourceIp` 分组聚合，支持：
- `filterAggregatedAlerts()` 按严重性过滤
- `getTopAttackers()` 获取TOP攻击者
- `calculateThreatRadar()` 计算雷达图维度值
