## 一、系统概述

### 1.1 PIDS系统简介

PIDS是御链天鉴平台的核心安全分析引擎，通过构建攻击行为的因果溯源图谱，结合AI智能分析技术，实现对网络攻击的自动化检测、溯源和响应。

### 1.2 核心能力矩阵

| 能力维度 | 功能描述 | 技术实现 | 状态 |
|----------|----------|----------|------|
| **实时溯源** | 基于进程和网络的实时攻击链追踪 | Scapy + psutil + 图谱构建 | ✅ 已实现 |
| **特征提取** | 130维多维度特征向量提取 | NetworkX + 统计分析 + NLP | ✅ 已实现 |
| **智能检测** | 基于机器学习的异常行为识别 | Isolation Forest/SVM/LOF | ✅ 已实现 |
| **性能评估** | 多维度检测效果量化评估 | sklearn.metrics + 可视化 | ✅ 已实现 |
| **可视化展示** | 交互式溯源图谱和特征分析 | AntV G6 + ECharts | ✅ 已实现 |
| **模型训练** | 自动化模型训练和优化 | AutoML + 超参数调优 | 🚧 规划中 |
| **威胁预测** | 基于历史数据的攻击预测 | LSTM + GNN | 🚧 规划中 |
| **自动响应** | 智能化攻击阻断和防御 | 规则引擎 + 自适应防御 | 🚧 规划中 |

### 1.3 系统价值

- **自动化程度高**：从人工分析（数小时）到AI自动分析（秒级）
- **检测准确率高**：综合准确率>93%，召回率>95%
- **可解释性强**：130维特征向量，每个维度都有明确含义
- **扩展性好**：支持多种模型、多种攻击类型、分布式部署

## 三、已实现功能详解

### 3.1 实时溯源与图谱构建

#### 3.1.1 功能概述

**核心能力**：基于网络流量和进程监控，实时构建攻击行为的因果溯源图谱。

**技术实现**：
- **网络抓包**：Scapy实时监听端口7888的TCP流量
- **进程监控**：psutil获取进程树、父子关系、命令行参数
- **特征识别**：支持5大类攻击特征（SQL注入、XSS、Webshell、目录遍历、RCE）
- **图谱构建**：自动生成节点（攻击源、进程、文件、网络）和边（执行、读写、连接）
- **实时推送**：通过HTTP POST推送到Spring Boot后端，WebSocket广播到前端

#### 3.1.2 支持的攻击类型

| 攻击类型 | 特征关键词 | 典型进程链 |
|----------|------------|------------|
| SQL注入攻击 | `union select`, `or 1=1`, `information_schema` | nginx → php-fpm → mysql → users.ibd |
| XSS跨站脚本 | `<script>`, `javascript:`, `onerror=` | nginx → php-fpm → node → malicious.js |
| Webshell上传 | `<?php`, `eval(`, `base64_decode` | nginx → php-fpm → cp → shell.php |
| 目录遍历攻击 | `../etc/passwd`, `..\\windows` | nginx → php-fpm → cat → /etc/passwd |
| 远程命令执行 | `whoami`, `id`, `uname`, `system(` | nginx → php-fpm → bash → whoami |

#### 3.1.3 溯源图谱数据结构

```json
{
  "nodes": [
    {
      "id": "attacker_1",
      "label": "10.138.50.151",
      "type": "attacker"
    },
    {
      "id": "process_nginx",
      "label": "nginx",
      "type": "process",
      "pid": 1234,
      "cmdline": "nginx: worker process"
    },
    {
      "id": "file_passwd",
      "label": "/etc/passwd",
      "type": "file"
    }
  ],
  "edges": [
    {
      "source": "attacker_1",
      "target": "process_nginx",
      "label": "攻击"
    },
    {
      "source": "process_nginx",
      "target": "file_passwd",
      "label": "读取"
    }
  ]
}
```

### 3.2 130维特征提取引擎

#### 3.2.1 功能概述

**核心能力**：将溯源图谱转化为130维结构化特征向量，为机器学习模型提供输入。

**特征分组**：
- 图结构特征：15维
- 节点特征：40维
- 边特征：25维
- 序列特征：30维
- 语义特征：20维

#### 3.2.2 特征维度详解

**1. 图结构特征 (15维)**

| 特征名称 | 说明 | 计算方法 |
|----------|------|----------|
| node_count | 节点总数 | len(nodes) |
| edge_count | 边总数 | len(edges) |
| graph_density | 图密度 | edges / (nodes * (nodes-1)) |
| avg_degree | 平均度数 | sum(degrees) / node_count |
| max_degree | 最大度数 | max(in_degree + out_degree) |
| min_degree | 最小度数 | min(in_degree + out_degree) |
| max_path_length | 最大路径长度 | 最长攻击链深度 |
| avg_path_length | 平均路径长度 | 所有路径长度均值 |
| connected_components | 连通分量数 | 独立子图数量 |
| clustering_coefficient | 聚类系数 | 节点聚集程度 |
| graph_diameter | 图直径 | 最远节点距离 |
| graph_radius | 图半径 | 中心节点到最远节点 |
| node_edge_ratio | 节点边比例 | nodes / edges |
| leaf_node_ratio | 叶子节点比例 | 出度为0的节点占比 |
| hub_node_ratio | 枢纽节点比例 | 度数>平均值2倍的节点占比 |

**2. 节点特征 (40维)**

- **节点类型统计 (5维)**：process、file、socket、attacker、other
- **关键进程频率 (35维)**：
  - 系统工具：bash、sh、python、perl、ruby
  - 网络工具：wget、curl、nc、netcat、nmap
  - 数据库：mysql、psql、redis、mongod
  - Web服务：nginx、apache、php-fpm、java、node
  - 敏感进程：ssh、sshd、sudo、su、chmod

**3. 边特征 (25维)**

- 边类型分布：执行、读取、写入、网络连接、fork
- 跨类型边统计：process→file、process→socket、file→process
- 链长度分布：平均链长、最大链长
- 分支因子：平均分支数、最大分支数
- 关键路径长度：攻击源到敏感文件的最短路径

**4. 序列特征 (30维)**

- 时间跨度：首次操作到最后操作的时间差
- 操作间隔统计：
  - 均值、方差、标准差
  - 最大值、最小值、中位数
  - 25分位数、75分位数
- 突发检测：短时间内大量操作的指标
- 序列长度：总操作数
- 唯一操作数：去重后的操作类型数

**5. 语义特征 (20维)**

| 特征名称 | 检测模式 | 得分计算 |
|----------|----------|----------|
| sql_injection_score | union、select、drop、insert、update | 匹配关键词数 / 总关键词数 |
| xss_score | `<script>`、onerror=、onload=、javascript: | 同上 |
| webshell_score | `<?php`、eval(、system(、exec( | 同上 |
| rce_score | whoami、id、uname、cat、ls、pwd | 同上 |
| privilege_escalation_score | sudo、su、chmod、chown | 同上 |
| data_exfiltration_score | scp、ftp、curl、wget | 同上 |
| persistence_score | crontab、systemd、.bashrc、.profile | 同上 |
| sensitive_file_access | /etc/passwd、/etc/shadow、id_rsa | 同上 |
| ...(共20维) | ... | ... |

### 3.3 AI行为建模系统

#### 3.3.1 功能概述

**核心能力**：基于正常行为特征训练异常检测模型，自动识别异常攻击行为。

**支持的模型**：
- **Isolation Forest**：孤立森林，快速检测，训练时间2-5分钟
- **One-Class SVM**：单类支持向量机，小样本场景，训练时间1-3分钟
- **Local Outlier Factor**：局部异常因子，密度检测

#### 3.3.2 模型训练流程

```
数据收集 → 特征提取 → 数据预处理 → 模型训练 → 模型评估 → 模型部署
   ↓           ↓            ↓            ↓           ↓           ↓
正常/异常   130维向量   归一化/标准化  选择算法   验证集测试  生产环境
溯源图谱                 缺失值处理    调参优化   性能指标
```

#### 3.3.3 训练数据要求

| 数据类型 | 数量要求 | 标签 | 来源 |
|----------|----------|------|------|
| 正常行为样本 | ≥1000条 | 0 | 日常系统运行产生的溯源图 |
| 异常行为样本 | ≥200条 | 1 | 攻击测试产生的溯源图 |
| 验证集 | 20%总量 | 已知标签 | 混合采样 |

#### 3.3.4 异常检测示例

**输入**：130维特征向量
```python
features = [0.15, 0.08, 0.23, ..., 0.91]  # 130维
```

**输出**：检测结果

### 3.4 检测性能评估

#### 3.4.1 功能概述

**核心能力**：多维度评估异常检测模型的性能，提供量化的评估指标。

**评估指标体系**：
- 基础指标：准确率、精确率、召回率、F1分数、AUC-ROC
- 混淆矩阵：TP、TN、FP、FN
- 分类别指标：各攻击类型的检测率
- 效率指标：检测延迟、吞吐量

#### 3.4.2 评估指标详解

| 指标 | 说明 | 计算公式 | 目标值 |
|------|------|----------|--------|
| **准确率 (Accuracy)** | 正确预测的比例 | (TP+TN)/(TP+TN+FP+FN) | ≥93% |
| **精确率 (Precision)** | 预测为攻击中真正是攻击的比例 | TP/(TP+FP) | ≥90% |
| **召回率 (Recall)** | 实际攻击中被正确检测的比例 | TP/(TP+FN) | ≥95% |
| **F1分数** | 精确率和召回率的调和平均 | 2×P×R/(P+R) | ≥92% |
| **AUC-ROC** | ROC曲线下面积 | 综合评估指标 | ≥0.95 |

#### 3.4.3 混淆矩阵示例

```
                预测结果
              正常    异常
实际  正常 │  1180  │   67  │  TN=1180, FP=67
结果  异常 │   12   │  300  │  FN=12,   TP=300

准确率 = (1180+300)/(1180+67+12+300) = 94.9%
精确率 = 300/(300+67) = 81.7%
召回率 = 300/(300+12) = 96.2%
F1分数 = 2×0.817×0.962/(0.817+0.962) = 88.3%
```

#### 3.4.4 分类别检测率

| 攻击类型 | 检测率 | 误报率 | 漏报率 |
|----------|--------|--------|--------|
| SQL注入攻击 | 96% | 2% | 4% |
| 远程命令执行 | 98% | 1% | 2% |
| Webshell上传 | 95% | 2% | 5% |
| XSS跨站脚本 | 94% | 3% | 6% |
| 目录遍历攻击 | 93% | 4% | 7% |

### 3.5 可视化分析界面

#### 3.5.1 功能概述

**核心能力**：提供交互式的溯源图谱展示和特征分析界面。

**主要组件**：
- 溯源图谱可视化（AntV G6）
- 特征分析面板
- 130维特征点阵图
- 基线对比可视化
- 实时检测日志

#### 3.5.2 溯源图谱可视化

**技术实现**：基于AntV G6的交互式图谱

**节点类型**：
- 攻击源：红色三角形 + 脉冲动画
- 进程：紫色菱形
- 文件：绿色圆角矩形
- 网络：蓝色圆形

**交互功能**：
- 全屏放大
- 缩放控制（100%/150%/200%）
- 节点拖拽
- 悬停提示
- 节点高亮

#### 3.5.3 特征分析面板

**展示内容**：
1. **综合威胁评分**：0-100分，基于语义特征计算
2. **130维特征点阵图**：130个像素方块，颜色表示特征值
3. **特征分组进度条**：
   - 图结构特征（基线15%）
   - 节点特征（基线12%）
   - 边特征（基线18%）
   - 序列特征（基线14%）
   - 语义特征（基线10%）
4. **基线对比**：当前值 vs 正常基线，偏离>200%红色闪烁
5. **异步加载动画**：按序提取（图结构→节点→边→序列→语义），间隔300ms
6. **数字滚动效果**：特征值从0滚动到目标值，8步完成
7. **AI检测日志**：终端风格的实时日志输出

#### 3.5.4 UI特性

- **数字滚动**：模拟AI扫描效果
- **扫描线动画**：加载中的特征组显示扫描线
- **过载警告**：偏离基线>200%时进度条红色闪烁
- **点击下钻**：点击特征组展开详细特征项
- **实时更新**：WebSocket推送，秒级刷新

## 三、行为建模系统

### 3.1 功能说明

基于正常行为特征训练异常检测模型，实现**无监督/半监督异常检测**。

### 3.2 支持的模型类型

| 模型 | 类型 | 适用场景 | 特点 |
|------|------|----------|------|
| **Autoencoder** | 深度学习 | 通用异常检测 | 通过重构误差检测异常 |
| **Isolation Forest** | 集成学习 | 快速检测 | 孤立点检测，计算效率高 |
| **One-Class SVM** | 支持向量机 | 小样本场景 | 只需正常样本即可训练 |
| **GNN (图神经网络)** | 图学习 | 图结构异常 | 捕获图拓扑特征 |
| **LSTM** | 循环神经网络 | 序列异常 | 检测时序异常模式 |

### 3.3 训练流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│  数据收集    │ -> │  特征提取    │ -> │  模型训练    │ -> │  模型评估    │
│  (正常行为)  │    │  (130维向量) │    │  (选择算法)  │    │  (验证效果)  │
└──────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
```

### 3.4 展示效果

- **训练进度条**：实时显示模型训练进度
- **损失曲线图**：展示训练过程中的损失变化
- **异常得分仪表盘**：实时显示当前图谱的异常程度
- **阈值调节滑块**：允许用户调整检测灵敏度

## 四、检测性能评估

### 4.1 功能说明

多维度评估模型的检测准确性和效率，提供**量化的性能指标**。

### 4.2 评估指标

#### 4.2.1 基础指标

| 指标 | 说明 | 计算公式 |
|------|------|----------|
| **准确率 (Accuracy)** | 正确预测的比例 | (TP+TN) / (TP+TN+FP+FN) |
| **精确率 (Precision)** | 预测为攻击中真正是攻击的比例 | TP / (TP+FP) |
| **召回率 (Recall)** | 实际攻击中被正确检测的比例 | TP / (TP+FN) |
| **F1分数** | 精确率和召回率的调和平均 | 2×P×R / (P+R) |
| **AUC-ROC** | ROC曲线下面积 | 综合评估指标 |

#### 4.2.2 效率指标

| 指标 | 说明 |
|------|------|
| **检测延迟** | 从图谱输入到输出结果的时间 |
| **吞吐量** | 每秒可处理的图谱数量 |
| **资源占用** | CPU/内存使用情况 |

#### 4.2.3 分类别检测率

| 攻击类型 | 目标检测率 |
|----------|------------|
| SQL注入攻击 | ≥95% |
| XSS跨站脚本攻击 | ≥88% |
| Webshell上传攻击 | ≥92% |
| 远程命令执行 | ≥90% |
| 目录遍历攻击 | ≥85% |
| SSH暴力破解 | ≥93% |

## 七、价值总结

### 7.1 现有功能 vs 新增功能

| 现有功能 | 策划案新增功能 |
|----------|----------------|
| 手动查看溯源图 | AI自动提取特征向量 |
| 人工判断攻击类型 | 模型自动分类和检测 |
| 无法量化检测效果 | 多维度性能评估指标 |
| 单一展示方式 | 丰富的可视化组件 |

### 7.2 核心价值

1. **自动化**：将人工分析工作自动化，提升效率
2. **量化**：将主观判断转化为客观指标
3. **可视化**：丰富的图表展示，直观易懂
4. **可扩展**：支持多种模型，适应不同场景
