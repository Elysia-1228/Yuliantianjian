## 🚀 一键启动（推荐）

### 方法1: 在Windsurf终端内运行（不弹出新窗口）
```bash
# 首次使用需要先安装依赖
npm install

# 启动前后端（在同一终端内运行）
npm start
```

**注意**: 使用 `npm start` 会在同一终端内同时启动前后端，不会弹出新窗口。

### 方法2: 使用脚本（会弹出新窗口）
脚本位于 `scripts/` 文件夹:
- `scripts/start-all.bat` - 双击运行
- `scripts/start-all.ps1` - PowerShell: `.\scripts\start-all.ps1`

## 手动启动

### 启动后端
```powershell
$env:JAVA_HOME = "E:\JAVE JDK17"
$env:PATH = "C:\apache-maven-3.9.6\bin;$env:JAVA_HOME\bin;$env:PATH"
cd BackCode
mvn spring-boot:run -DskipTests
```

### 启动前端
```bash
cd FrontCode
npm install  # 首次运行需要
npm run dev
```

## 常见问题

### Q: 登录失败？
确保数据库已导入 `net_safe-v2.sql` 文件。

### Q: 后端启动失败（JAVA_HOME未定义）？
在PowerShell中手动设置环境变量:
```powershell
$env:JAVA_HOME = "E:\JAVE JDK17"
$env:PATH = "C:\apache-maven-3.9.6\bin;$env:JAVA_HOME\bin;$env:PATH"
```

### Q: 前端页面空白？
确保已运行 `npm install` 安装依赖。

### Q: npm start弹出新窗口？
使用 `npm start` 命令会在当前终端运行，不会弹出新窗口。
如果之前弹出了新窗口，是因为使用了批处理脚本。
