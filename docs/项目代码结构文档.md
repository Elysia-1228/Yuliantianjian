## 1. 项目整体架构

### 1.1 项目根目录结构

```
Zhilian2025-master/
├── BackCode/                    # 主后端 Spring Boot 3.5.7 (Java 17)
├── backend/                     # 区块链网关 Spring Boot 2.7.12 (Hyperledger Fabric)
├── FrontCode/                   # 前端 React 18 + TypeScript + Vite
├── PythonIDS/                   # Python AI检测引擎
│   ├── PIDS/                   #   进程级入侵检测 (行为建模+VAE+集成学习)
│   └── NIDS/                   #   网络级入侵检测 (35+攻击类型, Scapy抓包)
├── RuleBasedIDS/                # 基于规则的IDS (类Snort规则引擎)
├── scripts/                     # 运维脚本
│   ├── host_monitor_agent.py   #   主机监控Agent (psutil采集)
│   ├── start-all.bat           #   Windows一键启动
│   └── start-all.ps1           #   PowerShell启动
├── docs/                        # 项目文档
├── test/                        # 测试数据与报告
├── dist/                        # 前端构建产物
├── net_safe-v2.sql             # 数据库初始化脚本
└── package.json                 # 项目启动配置 (concurrently管理前后端)
```

### 2.3 核心类说明

#### 2.3.1 控制器层 (Controller)

| 控制器 | 路径前缀 | 主要功能 |
|--------|---------|---------|
| **AuthController** | `/api/auth` | 用户登录认证，JWT Token颁发 |
| **MonitorController** | `/api/host/monitor` | 主机状态监控数据查询与上报 |
| **ThreatController** | `/api/threats` | 威胁告警处理、IP封禁/解封 |
| **AnalysisController** | `/api/analysis` | 威胁分析、流量统计、趋势图表 |
| **AiReportController** | `/api/report` | AI报告生成、历史管理 |
| **DashBoardController** | `/api/dashboard` | 仪表盘聚合数据 |
| **TracingController** | `/api/tracing` | 攻击溯源结果查询 |
| **CollectionHostController** | `/api/collection/host` | 数据采集主机配置 |
| **ReportShareController** | `/api/report/share` | 报告共享管理 |
| **UploadController** | `/api/upload` | 威胁情报文件上传 |

#### 2.3.2 服务层 (Service)

**核心服务接口**：
- `AuthService`: 用户认证、密码校验
- `MonitorService`: 主机监控数据CRUD、状态更新
- `ThreatService`: 威胁告警处理、封禁指令下发
- `CommandQueueService`: Redis指令队列管理

**服务实现特点**：
- 使用 `@Service` 注解标注
- 通过 `@Autowired` 注入Mapper
- 使用 `PageHelper` 实现分页
- 异常统一抛出由全局异常处理器捕获

#### 2.3.3 数据访问层 (Mapper)

**MyBatis Mapper接口**：
- 使用 `@Mapper` 注解
- XML文件定义SQL语句
- 支持动态SQL、结果映射

**示例 - MonitorMapper.java**：
```java
@Mapper
public interface MonitorMapper {
    List<hostStatusMonitor> queryHostMonitor(HostMonitorDTO dto);
    hostStatusMonitor queryHostMonitorByHostId(String hostId);
    void insertHostStatus(hostStatusMonitor status);
    void updateHostStatus(hostStatusMonitor status);
}
```

#### 2.3.4 实体类 (Entity)

**核心实体**：

1. **hostStatusMonitor** - 主机状态监控
   - `hostId`: 主机IP
   - `cpuUsage`: CPU使用率
   - `memoryUsage`: 内存使用率
   - `diskUsage`: 磁盘使用率
   - `networkConn`: 网络连接数
   - `fileStatus`: 文件状态(JSON)
   - `cpuModel`: CPU型号
   - `memoryInfo`: 内存信息
   - `diskPartitions`: 磁盘分区(JSON)

2. **potentialThreatAlert** - 威胁告警
   - `threatId`: 威胁ID
   - `sourceIp`: 攻击源IP
   - `targetIp`: 目标IP
   - `attackType`: 攻击类型
   - `severity`: 严重程度
   - `status`: 处理状态
   - `detectedTime`: 检测时间

3. **sysUser** - 系统用户
   - `username`: 用户名
   - `password`: 密码(MD5)
   - `role`: 角色
   - `status`: 状态

### 4.2 核心页面组件

#### 4.2.1 Login.tsx - 登录页
**功能**：
- 用户名密码登录
- JWT Token获取与存储
- 登录状态验证
- 自动跳转首页

**关键代码**：
```typescript
const handleLogin = async () => {
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    body: JSON.stringify({ username, password })
  });
  const data = await response.json();
  localStorage.setItem('token', data.data.token);
  navigate('/');
};
```

#### 4.2.2 Home.tsx - 首页仪表盘
**功能**：

- 最新告警列表
- 系统健康度展示

**数据源**：

#### 4.2.3 HostMonitoring.tsx - 主机安全监控
**功能**：
- CPU/内存/磁盘实时监控
- 磁盘分区详细展示
- 网络连接数图表
- 文件完整性监控

**特色**：
- 3D可视化磁盘卡片
- 动态颜色告警(>90%红色)
- 圆形进度指示器
- 扫描线动画效果

**数据格式**：
```typescript
interface HostStatus {
  hostId: string;
  cpuUsage: number;
  cpuModel: string;
  memoryUsage: number;
  memoryInfo: string;
  diskUsage: number;
  diskPartitions: Array<{
    name: string;
    percent: number;
    used: number;
    free: number;
    total: number;
  }>;
  fileStatus: Array<{
    path: string;
    status: 'normal' | 'missing' | 'protected';
  }>;
}
```

#### 4.2.4 ThreatAlerts.tsx - 威胁告警
**功能**：
- 威胁告警列表展示
- 严重程度筛选
- 一键封禁/解封IP
- 告警详情查看

**操作流程**：
1. 点击"封禁"按钮
2. 调用 `/api/threats/{id}/block`
3. 后端下发指令到Agent
4. 前端更新状态为"已封禁"

#### 5.1.2 核心功能

**130维特征提取**（5组）：

| 特征组 | 维度范围 | 数量 | 说明 |
|--------|---------|------|------|
| 图结构 | 0-14 | 15 | 节点数、边数、密度、聚类系数等 |

| 序列 | 80-109 | 30 | 时间跨度、爆发次数、操作熵等 |
| 语义 | 110-129 | 20 | SQL注入/XSS/WebShell/RCE得分 |

**L1+L2双层检测**：
- L1（快速筛选）：集成学习 (Isolation Forest + LOF + OCSVM + XGBoost)
- L2（深度确认）：VAE + MLP 分类器
- 融合策略：`final_score = 0.3 × L1 + 0.7 × L2`

**API端点**（端口7890）：

|------|------|------|

## 7. 功能模块详解

### 7.1 认证授权模块

**技术实现**：JWT Token

**流程**：
1. 用户输入用户名密码
2. 后端验证 → 生成JWT Token
3. 前端存储Token到localStorage
4. 后续请求携带Token在Header中
5. 后端拦截器验证Token有效性

**关键代码**：
```java
// JwtUtil.java
public static String createJWT(String secretKey, long ttl, Map<String, Object> claims) {
    return Jwts.builder()
        .setClaims(claims)
        .setExpiration(new Date(System.currentTimeMillis() + ttl))
        .signWith(SignatureAlgorithm.HS256, secretKey)
        .compact();
}
```

### 7.2 主机监控模块

**架构**：Agent → Backend → Frontend

**Agent功能** (`host_monitor_agent.py`):

- 每3秒上报一次数据
- 支持Windows/Linux双平台
- 获取CPU型号、内存类型、磁盘分区

**数据流**：
```
Agent采集 → POST /api/host/monitor/report → 
MySQL存储 → GET /api/host/monitor/realtime/{hostId} → 
前端展示
```

**核心指标**：
- CPU使用率、型号、核心数、频率
- 内存使用率、类型、总容量
- 磁盘使用率、分区详情
- 网络连接数
- 文件完整性状态

### 7.3 威胁检测与响应模块

**检测引擎**：

**响应流程**：
```
检测引擎发现威胁 → 
POST /api/analysis/alert (上报告警) → 
安全分析师确认 → 
POST /api/threats/{id}/block (下发封禁指令) → 
指令进入Redis队列 → 
Agent轮询获取指令 → 
执行防火墙规则 → 
IP被封禁
```
