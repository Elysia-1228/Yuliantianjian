### 4. 如何修改前端界面

修改任意 `.tsx` 文件后，Vite会自动热更新，无需重启服务。

示例 - 修改登录页标题：
```tsx
// 文件: FrontCode/src/pages/Login.tsx
// 第61行
<h1>御链天鉴</h1>  // 可直接修改此处文字
```
