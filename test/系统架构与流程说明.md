## 二、完整数据流程

### 2.1 攻击检测与告警推送流程

```
步骤1: 发起攻击
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Windows: python attack_menu.py
    选择攻击类型 (SQL注入/XSS/Webshell/目录遍历/远程命令执行)
    ↓
    发送TCP请求到 Linux靶机 10.138.50.151:7888
    
步骤2: 靶机接收请求
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Linux: vulnerable_server.py
    ↓
    检测攻击特征 → 执行模拟命令 (生成真实进程)
    例如: SQL注入 → 执行 mysql 查询
         远程命令执行 → 执行 whoami, id, uname
    ↓
    返回HTTP响应 "Hacked! Server pwned!"

步骤3: PIDS进程溯源
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Linux: pids_server_v3.py (Scapy抓包)
    ↓
    检测攻击特征 → 查找靶机进程 → 监控进程树
    ↓
    构建溯源图谱:
    {
        "nodes": [攻击源, 靶机服务器, nginx, php-fpm, mysql, users.ibd],
        "edges": [攻击源→靶机, 靶机→nginx, nginx→php-fpm, ...]
    }
    ↓
    POST http://Windows后端IP:8985/api/analysis/alert

步骤4: NIDS AI检测
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Linux: nids_server.py (Scapy抓包 + DPI)
    ↓
    深度包检测 → 特征匹配 (SQL注入: "union select", XSS: "<script>", ...)
    ↓
    构建告警数据:
    {
        "threatId": "uuid",
        "threatLevel": 5,
        "impactScope": "攻击源IP -> 目标IP | 攻击类型",
        "attackType": "SQL注入攻击",
        "affectedProcess": ["nginx", "php-fpm", "mysql"],
        "affectedFile": "/var/lib/mysql/users.ibd"
    }
    ↓
    POST http://Windows后端IP:8985/api/analysis/alert

步骤5: 后端处理与推送
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Windows: BackCode (Spring Boot)
    ↓
    AnalysisController.receiveAlert()
    ↓
    保存到MySQL数据库 (potential_threat_alert表)
    ↓
    WebSocketServer.sendInfo(json) → 广播到所有前端客户端

步骤6: 前端实时展示
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    Windows: FrontCode (React)
    ↓
    IDSSocket 接收WebSocket消息 → 解析为ThreatEvent
    ↓
    ThreatAlerts.tsx 更新告警列表 → 实时显示
    ThreatTracing.tsx 更新溯源图谱 → AntV G6渲染
```

## 四、启动顺序

### 4.1 Windows端启动

```powershell
# 1. 启动MySQL数据库 (确保服务已运行)

# 2. 启动后端服务
cd BackCode
mvn spring-boot:run
# 或在IntelliJ IDEA中运行BackCodeApplication

# 3. 启动前端服务
cd FrontCode
npm install
npm run dev
# 访问 http://localhost:3002
```

### 4.2 Linux靶机启动

```bash
# SSH连接到靶机服务器
ssh root@10.138.50.151

# 进入脚本目录
cd /path/to/server_scripts

# 1. 启动靶机服务 (终端1)
python3 vulnerable_server.py

# 2. 启动PIDS进程溯源引擎 (终端2, 需要root权限)
sudo python3 pids_server_v3.py

# 3. 启动NIDS AI检测引擎 (终端3, 需要root权限)
sudo python3 nids_server.py
```

### 4.3 执行攻击测试 (Windows)

```powershell
cd test
python attack_menu.py

# 选择攻击类型:
# [1] SQL注入攻击
# [2] XSS跨站脚本攻击
# [3] Webshell上传攻击
# [4] 目录遍历攻击
# [5] 远程命令执行
# [6] 系统侦查
# [A] 自动连续攻击
# [B] 批量攻击
```

## 七、攻击类型与进程链映射

| 攻击类型 | 进程链 | 受影响文件 |
|----------|--------|------------|
| SQL注入攻击 | nginx → php-fpm → mysql | /var/lib/mysql/users.ibd |
| XSS跨站脚本攻击 | nginx → php-fpm → node | /var/www/html/malicious.js |
| Webshell上传攻击 | nginx → php-fpm → cp | /var/www/html/shell.php |
| 目录遍历攻击 | nginx → php-fpm → cat | /etc/passwd |
| 远程命令执行 | nginx → php-fpm → bash → whoami | /tmp/rce_output.txt |
| SSH暴力破解 | sshd → pam_unix | /var/log/auth.log |

## 八、故障排查

### 8.1 告警不推送到前端

**检查步骤**:
1. 确认Windows后端已启动 (端口8985)
2. 确认Linux脚本中的 `JAVA_IP` 配置正确
3. 检查Windows防火墙是否放行8985端口
4. 查看Linux脚本日志是否有连接错误

### 8.2 靶机服务无响应

**检查步骤**:
1. 确认 `vulnerable_server.py` 已启动
2. 确认防火墙放行7888端口
3. 测试: `telnet 10.138.50.151 7888`

### 8.3 PIDS/NIDS无法抓包

**检查步骤**:
1. 确认使用root权限运行: `sudo python3 pids_server_v3.py`
2. 确认网卡配置正确 (IFACE变量)
3. 检查Scapy是否安装: `pip3 install scapy`
